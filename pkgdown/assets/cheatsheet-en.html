Install and run everything

Example data: nedap, fire (raw station exports).

Read data read_station() / station_format()

# a whole folder; without station the type is detected
read_station("export/", station = "nedap")
read_station(c("101.xlsx", "102.xlsx"), station = "fire")
# other column names: write a template, edit column
station_format("fire", file = "fire_format.txt")
read_station("export/", station = "fire",
             format = "fire_format.txt")
  • CSV, TXT (separator detected) and Excel (needs readxl).
  • No format file is needed when the columns match the built-in format; otherwise an error lists the missing columns.
  • Format file, one line per field: field, column (name or position; Date,Entry joins two columns; - if absent), unit (kg / g / auto, s / min).
  • Result is one standard table: IDs and stations as text; times as POSIXct; feed and trough weights in g, body weight in kg, duration in s.

Visits and breed prep_visits() / add_breed()

visits <- prep_visits(raw)
visits <- add_breed(visits, read.csv("breeds.csv"),
                    id = "tag", breed = "breed")
  • Visits of unidentified transponders are kept as identified = FALSE (needed for the feeder error rules).
  • Pigs at several stations: all stays kept (also back to a former station); runs of ≤ 2 visits inside another station's visits are misreads, kept as unidentified; gaps > 3 d or weight jumps > 10 kg flag the pig. See attr(visits, "stations").
  • With a breed column, the correction model gets a breed effect and fcr$summary is split by breed.

Weight cleaning clean_weight()

Daily gain calc_adg()

  1. The growth curve sets the stage: end = first time at the upper limit, start = last rise through the lower limit before it.
  2. Every stage day gets a weight, weight_filled:
sourceFrom
observedmedian of the day's valid weights
interpolatedbetween recorded days: linear interpolation
curvebefore the first / after the last record: growth curve (tangent with curve_extrap = "tangent")

3. ADG = slope of the daily weights on the day over the stage (g/d), with r_squared.

adg_typeMeaning
observedboth stage limits inside the test
extrapolatedextrapolated, at most 30 days
partiala limit is never reached: covered part only
noneless than 7 days covered, no ADG

Feed intake flag_feed_errors() / calc_adfi()

  • Errors: the 16 rules of Casey et al. (2005) (feed per visit, duration, feeding rate, trough weight differences…); run inside calc_adfi().
  • Correction: mixed model of Jiao et al. (2014), removes the effect of the error covariates; days without errors unchanged.
  • Filling: on the ADG stage days only, with the filled daily weights. Long gaps and stage ends: population (or breed) curve of intake on body weight × the pig's intake level, see adfi$pop_curve.
stateThe day's intake is
orgrecorded, no error visit that day
corrcorrected by the model
iiigap between records: ≤ 3 d LOESS, > 3 d population curve × pig level
elrpmissing at the stage ends: population curve × pig level
missingcannot be estimated

ADFI = mean daily intake over the stage; coverage = share of days recorded (incl. corrected).

Feed conversion calc_fcr()

FCR = ADFI ÷ ADG, gf = ADG ÷ ADFI. fcr_flag is ok or low_confidence; why is in fcr_note:

  • weights or feed filled for more than 15 days at a stage end;
  • feed recorded on less than 70% of the stage;
  • an inner 10 kg class covered by less than 6 kg of recorded weights;
  • ADG on part of the stage, or weight data flagged;
  • optional: class FCR outside bin_fcr_limits.

Per class: fcr$by_bin; summary: fcr$summary (all / ok / per breed). For breeding values prefer pigs with fcr_flag == "ok".

Common settings

# late entry (45-60 kg)
qc_config(stage_range = c(60, 120), curve_model = "poly1")
# slaughter at about 115 kg
qc_config(stage_range = c(30, 110))
# planned test of 50 days
qc_config(min_test_days = 30)
# FIV limit by body weight + class FCR check
qc_config(fiv_max_by_weight = fiv_max_example(),
          bin_fcr_limits = bin_fcr_example())
# thousands of pigs: parallel
run_pipeline(raw, cores = 4)
# one station, a few pigs
plot_adg(res$adg, locations = "101", responders = c("13913"))
  • Lower stage limit 5–10 kg above typical entry weight, upper limit about 5 kg below typical exit weight.
  • Keep one set of settings for a breeding herd, so that years stay comparable.
Methods: Casey et al. (2005) feeder errors; Jiao et al. (2014) robust regression and feed correction; Cleveland (1979) LOESS. Details (in Chinese): methods, QC parameters, output tables.
